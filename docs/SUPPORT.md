# Support

- Bugs: open a [bug report](https://github.com/LuchoNoPrograma/nini-agents/issues/new?template=bug.yml).
- Usage: open a [usage question](https://github.com/LuchoNoPrograma/nini-agents/issues/new?template=question.yml).
- New AI tools: open an [AI tool request](https://github.com/LuchoNoPrograma/nini-agents/issues/new?template=ai-tool.yml).
- Vulnerabilities: use [private security reporting](https://github.com/LuchoNoPrograma/nini-agents/security/advisories/new).

Run `nini-agents doctor` first. Include the Nini Agents version, operating system, shell, AI tool, reproduction steps, and sanitized output. Never post credentials or private account data.
